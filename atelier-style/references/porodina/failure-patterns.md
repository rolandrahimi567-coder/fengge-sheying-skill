# Porodina 失败模式与验证问题

以下为用户问题及助手提出的验证方向，均不代表已找到有效解法。

| 用户问题 | 反馈 | 下次检查 |
|---|---|---|
| AI感、塑料皮肤、动漫化 | PF-1721、PF-1777、PF-1854 | 整体摄影感、肤色起伏、材料差异；不靠统一锐化 |
| 几乎都是半身，动作题材少 | PF-2122、PF-2888 | 批次景别和动作分布是否重复 |

| 没理解摄影参考、构图靠臆想 | PF-3891 | 明确参考关系与变化内容，再逐项看实际输出 |
| 墙壁假 | PF-3141 | 背景是否擅自添加建筑 |
