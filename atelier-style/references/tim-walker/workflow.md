# Tim Walker 参考图编译与实验流程

用户于 2026-09-17 要求参照 Porodina 的生图流程继续已有分类。默认走本流程；明确要求原有纯文字模式时才读 ../legacy-generation-workflow.md。本流程是参考选择和提示组织的实验方法，不是已验收的风格配方。

## 原图库与分类

读取 category-rules.json 和 reference-index.json。150 张沿用原分类：A3、B14、C15、D6、E6、F9、G5、H3、暂不归类89。2026-09-17 已核对所有本地副本 SHA256 与清单一致。摄影师归属沿用原图库标签，未独立认证；这些是原图库的分析尺寸图，不宣称为相机原片。分类不是用户逐图验收。保持原分类、原图及不确定项，不为凑数重分。

## 选择与生成

保留完整用户原话，按题材选适合的类别，再查看候选完整图片。摄影原作每次输入一张；确实风格一致才输入两张。默认再选择一张服装参考，并单独检查其衣形、结构、材料、工艺与用户指定颜色。摄影原作控制衣形与身体的关系、构图、人物尺度、空间、灯光及整体摄影表达；服装参考不控制模特身份、姿势、构图、景别、背景、秀场、建筑、观众、灯光或整体调色。用户明确不要服装参考时记录原因。同类、同作者、相似姿态并不能证明摄影原作风格一致。同场景裁切不得当作独立证据。不使用整类拼版作为本模式默认输入。

用中文写连贯的整体画面描述：题材与景别、Tim Walker 姓名、所选图可见的衣形—身体—空间关系、参考作用及必要限制。用户未给题材时可设计简单新题材，明确记为助手设计。不要把八类拼成一套形容词；巨大道具、梦幻森林、复古室内、拖影均不是通用必选项。不要移植 Porodina 的高饱和重叠或 Roversi 的柔化拖影默认值，也不移植其特定失败题材禁用记录。

背景按当前参考和用户需求确定，不能把平面色底擅自改为建筑。关注真实皮肤、衣料厚度与重量、身体支撑和人物环境接触，不用全局锐化或去色代替摄影感。参考用于表达关系，不要求复制人脸、具体衣装、独特道具或完整构图。

使用内置 imagegen，并遵守 imagegen skill。通常一张；开放探索先两次调用，保留每次首次结果及失败，不自动重抽或更换供应商。保存请求、选择理由、实际提交参数、参考输入顺序与哈希、输出路径或原始错误。

完成看图和参考计划后，使用 `scripts/prepare_tim_walker_generation.py` 编译任务。编译器要求类别、一张或两张摄影原作、选择理由、完整看图记录、中文摄影参考计划，以及默认的一张服装参考和中文服装计划；两张摄影原作必须显式确认风格一致。它校验原作与服装参考的路径和哈希及摄影原作类别归属，输出一张图片对应的标准 imagegen 参数，不自动选图、生图、重试或确认风格通过。

```sh
python scripts/prepare_tim_walker_generation.py \
  --request-file REQUEST.txt \
  --category C \
  --photo-ref 5 \
  --selection-reason '衣形与角色关系适合本次题材' \
  --inspection-file INSPECTION.txt \
  --reference-plan-file REFERENCE_PLAN.txt \
  --clothing-reference CLOTHING.jpg \
  --clothing-plan-file CLOTHING_PLAN.txt \
  --out JOB.json
```

多题材和多张测试分别编译独立任务。用户明确不要服装参考时，以 `--no-clothing-reference-reason '用户明确要求仅用摄影参考'` 记录本次覆盖。用户明确指定选角时增加 `--explicit-casting`；用户明确要求与参考不同的背景空间时增加 `--background-override`。

## 交付与评估

画廊每个结果旁展示实际提交参考，按输入顺序放置，可点击原尺寸，保留比例；失败项显示参考和错误，不补成成功。提供完整中文提示词。技术记录保存在内部，画廊保持简洁。

分别记录助手观察与用户评价，检查题材、整体摄影感、衣形与身体、空间和材质、构图及复制风险。无用户反馈保持 unreviewed。多个新题材和景别获用户认可后才讨论可复用性；成功出图不等于风格已验证。

首轮记录见 reviews.json。231 和 279 是近似同场景的不同版本，本轮只提交231；254单独用于环境测试。这是本轮选择，不是永久默认参考。

## 2026-09-17 新题材反馈：背景失败

最新题材批次02「夜班售票员」、03「厨房里的小麦田」被用户明确拒绝：“超级假，参考图精髓一点没学到，尤其是背景”。这两套具体提示不能作为正面配方继续推广。其他图片仍未评价。

复看观察：277参考为简洁蓝底、紧凑角色轮廓与透明材质反光；02自行添加整条夜街、售票亭及冷暖电影照明，背景结构没有参考支持。113参考依靠少量墙面、门框、大块暗部和一处明亮门洞、沙面改变空间规则；03扩成密集厨具、做旧陈设、满地麦秆与暖光，空间密度和光色组织均偏离。助手先前将“空间可读”当作有潜力的依据不足，不能等同摄影真实感或风格迁移。

后续跨题材实验先判断参考是否支持所需的背景形式、空间密度、明暗分区和人物比例；缺乏对应空间参考时重新选图，不只抽取蓝色或“室内自然侵入”等主题概念，再自行扩写完整背景。新题材可以改变内容，但不自动添加做旧、湿地反光、复古建筑或电影冷暖光作为真实感捷径。这是针对本次失败的修正方向，尚未验证有效；不构成对所有街景、厨房或复杂布景的永久禁用。
